# Política de seguridad

Ágora es un proyecto personal de Juan Diego Pardo Pozo.

## Cómo reportar una vulnerabilidad

No abras un issue público. Usa el reporte privado de GitHub (pestaña **Security → Report a vulnerability**) o escribe a jdiegopardo23@gmail.com con:

- una descripción del problema y su impacto;
- los pasos para reproducirlo;
- la versión o el commit afectado.

Recibirás una respuesta en un plazo de 7 días. Te pido que no divulgues el problema hasta que esté corregido.

## Versiones con soporte

Solo la última versión publicada en `main` recibe correcciones de seguridad.
