# HU-09.04 · Editar los datos de una materia

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **estudiante**, quiero **corregir el docente, el aula, el horario o los pesos de una materia**, para **mantener la información al día cuando cambia algo en el semestre**. |
| **Contexto** | «Editar» en el detalle de la materia abre el mismo formulario de HU-09.01 con los datos cargados. |
| **Reglas de negocio** | RN-1: mismas validaciones que el alta. · RN-2: cambiar un horario actualiza los eventos futuros del calendario (los pasados no se tocan). · RN-3: cambiar el código SIS no está permitido si hay documentos del Olimpo asociados; se muestra el motivo. · RN-4: cambiar el nombre **no** renombra la carpeta de Drive (se avisa: «La carpeta de Drive conserva su nombre.»). |
| **Datos** | Mismas tablas que HU-09.01. |
| **Supuestos** | |
| **Fuera de alcance** | Cambio de aula desde Avisos (HU-13.02). |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Editar una materia

  Escenario: CA-FE-01 Cambiar el aula
    Dado la materia "Base de Datos II"

    Entonces el detalle muestra "690B" y las próximas clases del calendario también

  Escenario: CA-FE-02 Código bloqueado
    Dado que la materia tiene documentos del Olimpo
    Entonces el campo "Código SIS" está deshabilitado con "No se puede cambiar: hay documentos asociados."

  Escenario: CA-FE-03 Renombrar
    Cuando cambio el nombre
    Entonces al guardar veo el aviso "La carpeta de Drive conserva su nombre."
```
