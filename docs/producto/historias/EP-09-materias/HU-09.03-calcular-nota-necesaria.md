# HU-09.03 · Calcular la nota necesaria para aprobar una materia

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **estudiante**, quiero **registrar mis notas y ver cuánto necesito en lo que falta para aprobar con 51**, para **saber cuánto esfuerzo dedicar a cada evaluación**. |
| **Contexto** | Bloque «Notas» del detalle de materia. |
| **Reglas de negocio** | RN-1: tabla «Evaluación · Peso · Nota · Aporte» con las evaluaciones de la materia. · RN-2: nota de 0 a 100 (enteros o con un decimal, con coma); vacía = «pendiente». · RN-3: aporte = nota × peso ÷ 100, redondeado a un decimal (mitad hacia arriba). La nota necesaria se redondea **hacia arriba** al entero (16,7 → 17). · RN-4: «Acumulado {x} / 100». · RN-5: nota necesaria = (51 − acumulado) ÷ (suma de pesos pendientes ÷ 100). Mensajes: si ≤ 100, «Necesitas {n} en {pendientes} para aprobar con 51.»; si ya alcanza 51, «Ya aprobaste con {x}.»; si > 100, «Ya no es posible llegar a 51 con lo que falta.». · RN-6: la nota mínima de aprobación (51) es un parámetro de `perfil` con 51 por defecto. |
| **Datos** | `evaluaciones(materia_id, nombre, peso, nota)`. |
| **Supuestos** | La escala de la UMSS es de 0 a 100 con aprobación en 51. |
| **Fuera de alcance** | |
