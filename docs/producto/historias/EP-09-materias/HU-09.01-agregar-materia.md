# HU-09.01 · Agregar una materia con horario, docente y carpeta de Drive

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **estudiante**, quiero **registrar una materia con su código, horario, docente, evaluación y color**, para **que el Olimpo, la agenda, la malla y Drive la conozcan desde el primer día**. |
| **Contexto** | `/materias/nueva` (también desde «Agregar materia» en la cabecera del Olimpo y «+ Agregar materia» en el listbox del encargo). Subtítulo: «El Olimpo la usará para encargos, Drive, calendario y malla.». |
| **Reglas de negocio** | RN-1: obligatorios: **Nombre*** y **Código SIS*** (7 dígitos, único). · RN-2: datos generales: grupo, semestre del plan (1 a 10), gestión (p. ej. «II/2026») y estado (Cursando, Por cursar, Aprobada). · RN-3: docente, correo (`@umss.edu` o `@fcyt.umss.edu.bo` sugerido, cualquier correo válido aceptado), auxiliar y consultas. · RN-4: horarios: día, inicio, fin (fin > inicio), aula y tipo (Teoría, Laboratorio, Auxiliatura); cada horario **se crea en el calendario** como evento recurrente de la gestión. · RN-5: contenido: descripción y unidades (contexto para el Olimpo). · RN-6: pesos de evaluación (Parcial 1 %, Parcial 2 %, Prácticas %) que deben **sumar 100**. · RN-7: prerrequisitos (multiselección desde `plan_materias`). · RN-8: color: pastel sugerido según el orden (`docs/design.md` sección 2.2), editable. · RN-9: Google Drive: «Crear carpetas automáticamente» activado crea `Mi unidad / UMSS / {nombre} / {Bot, Apuntes, Prácticas}`. · RN-10: «* Obligatorio» al pie; «Guardar materia» lleva al detalle de la materia. |
| **Datos** | `materias`, `materia_horarios`, `materia_unidades`, `evaluaciones`, `plan_prerrequisitos`. |
| **Supuestos** | La creación de carpetas usa la misma integración de Drive que el worker (orden en `ordenes_vm`). |
| **Fuera de alcance** | Editar (HU-09.04) y la malla (EP-10). |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Agregar una materia

  Escenario: CA-FE-01 Guardar una materia válida
    Dado que estoy en "/materias/nueva"
    Cuando escribo "Base de Datos II", el código "2010016", el horario "Lunes 09:45 a 11:15" y pesos 30, 30 y 40
    Y hago clic en "Guardar materia"
    Entonces llego a "/materias/2010016" con el toast "Base de Datos II agregada"

  Esquema del escenario: CA-FE-02 Validación del código SIS
    Cuando escribo <codigo> en "Código SIS" y salgo del campo
    Entonces veo <mensaje>

    Ejemplos:
      | codigo  | mensaje                                   |
      | 2010    | El código SIS debe tener 7 dígitos.       |
      | 201001A | El código SIS debe tener 7 dígitos.       |
      | 2010016 | ✓                                         |

  Escenario: CA-FE-03 Código repetido
    Dado que ya existe la materia "2010016"
    Cuando intento guardar otra con el mismo código
    Entonces veo "Ya tienes una materia con el código 2010016."

  Escenario: CA-FE-04 Pesos que no suman 100
    Cuando escribo 30, 30 y 30 en los pesos
    Entonces veo "Los pesos suman 90 %. Deben sumar 100 %." y no se puede guardar

  Escenario: CA-FE-05 Horario inválido
    Cuando agrego un horario de 11:15 a 09:45
    Entonces veo "La hora de fin debe ser posterior a la de inicio."

  Escenario: CA-FE-06 Horario en el calendario
    Dado que guardé "Base de Datos II" con "Lunes 09:45 a 11:15"
    Cuando abro "/agenda/horario"
    Entonces veo el bloque "Base de Datos II" el lunes de 09:45 a 11:15

  Escenario: CA-FE-07 Carpetas de Drive
    Dado "Crear carpetas automáticamente" activado
    Cuando guardo la materia
    Entonces la vista previa "Mi unidad / UMSS / Base de Datos II / ├ Bot ├ Apuntes └ Prácticas" se crea en Drive

  Escenario: CA-FE-08 Cancelar con cambios
    Dado que escribí el nombre
    Cuando hago clic en "Cancelar"
    Entonces veo "¿Descartar cambios?"
```
