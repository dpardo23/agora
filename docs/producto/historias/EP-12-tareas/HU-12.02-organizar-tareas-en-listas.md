# HU-12.02 · Organizar las tareas en listas y filtros

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **estudiante**, quiero **ver mis tareas por Hoy, Programadas, Completadas, por materia o en listas propias**, para **enfocarme en lo que toca ahora**. |
| **Contexto** | Columna de listas de `/tareas` (en móvil, chips horizontales). |
| **Reglas de negocio** | RN-1: listas fijas: **Todas**, **Hoy** (vence hoy o vencidas), **Programadas** (con fecha futura) y **Completadas**, con su contador. · RN-2: «Por materia»: una entrada por materia en curso, con su color. · RN-3: «+ Nueva lista» crea una lista propia (nombre de 1 a 40 caracteres, único). · RN-4: dentro de una lista, las tareas se agrupan por vencimiento («Vencidas», «Hoy», «Esta semana», «Más adelante», «Sin fecha»); las vencidas en `--warn`. · RN-5: marcar la casilla completa la tarea con un toast «Tarea completada» + «Deshacer». · RN-6: «Google Tasks · hace {n} min» indica la última sincronización (HU-12.05). |
| **Datos** | `listas_tareas(id, nombre, propia)`, `tareas`. |
| **Supuestos** | |
| **Fuera de alcance** | |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Organizar las tareas

  Escenario: CA-FE-01 Lista Hoy
    Dado 2 tareas que vencen hoy y 1 vencida ayer
    Cuando abro "Hoy"
    Entonces veo las 3 tareas, con la vencida en --warn bajo "Vencidas"

  Escenario: CA-FE-02 Completar con deshacer
    Cuando marco la casilla de "Práctica 3"
    Entonces la tarea pasa a "Completadas" y veo "Tarea completada" con "Deshacer"

  Escenario: CA-FE-03 Crear lista propia
    Cuando hago clic en "+ Nueva lista" y escribo "Tesis"
    Entonces aparece la lista "Tesis" y queda seleccionada

  Escenario: CA-FE-04 Filtrar por materia
    Cuando elijo "Estadística II" en "Por materia"
    Entonces solo veo las tareas de Estadística II

  Escenario: CA-FE-05 Lista vacía
    Cuando abro "Hoy" sin tareas
    Entonces veo "Nada para hoy" y el campo "Nueva tarea"
```
