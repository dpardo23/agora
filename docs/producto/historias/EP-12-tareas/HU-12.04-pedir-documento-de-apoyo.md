# HU-12.04 · Pedir al Olimpo un documento de apoyo desde una tarea

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **estudiante**, quiero **pedir al Olimpo un documento de apoyo para una tarea, ya o cuando falten 3 días**, para **tener material de estudio a tiempo sin acordarme de encargarlo**. |
| **Contexto** | Botón «Pedir al Olimpo un documento de apoyo» en el detalle de la tarea y casilla «Pedir al Olimpo un documento de apoyo cuando falten 3 días» en el diálogo «Nueva tarea». |
| **Reglas de negocio** | RN-1: el botón abre el formulario de encargo con la materia y el tema precargados (título de la tarea + notas como indicaciones). · RN-2: la casilla programa el encargo para 3 días antes del vencimiento a las 08:00; si faltan menos de 3 días al marcarla, se encarga de inmediato y se avisa. · RN-3: la tarea muestra el vínculo «Documento #{n} · {estado}». · RN-4: si la tarea no tiene materia, se pide elegirla antes de encargar. |
| **Datos** | `tareas.trabajo_id`, `tareas.encargo_programado_en`. |
| **Supuestos** | |
| **Fuera de alcance** | |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Pedir un documento de apoyo

  Escenario: CA-FE-01 Encargar desde la tarea
    Dado la tarea "Práctica 3: ejercicios de varianza" de Estadística II
    Cuando hago clic en "Pedir al Olimpo un documento de apoyo"
    Entonces se abre el encargo con "Estadística II" y el tema "Práctica 3: ejercicios de varianza"

  Escenario: CA-FE-02 Encargo programado
    Dado una tarea que vence el martes 20 y la casilla de 3 días marcada
    Entonces el encargo se crea el sábado 17 a las 08:00
    Y la tarea muestra "Documento programado para el sáb 17"

  Escenario: CA-FE-03 Sin materia
    Dado una tarea sin materia
    Cuando pido el documento
    Entonces veo "Elige la materia de la tarea para encargar el documento."
```
