# HU-12.01 · Crear una tarea rápida con Enter

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **estudiante**, quiero **anotar una tarea escribiendo una línea y presionando Enter**, para **capturarla en segundos sin llenar un formulario**. |
| **Contexto** | Campo «Nueva tarea · Enter» en `/tareas` (en móvil, el botón «+» abre la hoja «Nueva tarea»). |
| **Reglas de negocio** | RN-1: Enter crea la tarea en la lista actual y deja el campo vacío y con el foco. · RN-2: atajos en el texto (placeholder «Agregar tarea · escribe «mañana» o «#bd2» para fecha y materia»): «hoy», «mañana», nombre de un día («jueves») → vencimiento; «#{alias de materia}» → materia (alias = siglas del nombre, p. ej. «#bd2», «#est2»). · RN-3: los atajos reconocidos se quitan del título y se muestran como chips antes de crear. · RN-4: título de 1 a 200 caracteres. · RN-5: Esc vacía el campo. |
| **Datos** | `tareas(id, lista_id, titulo, materia_id, vence_en, completada_en, orden)`. |
| **Supuestos** | |
| **Fuera de alcance** | El detalle completo (HU-12.03). |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Crear una tarea rápida

  Escenario: CA-FE-01 Crear con Enter
    Dado que estoy en la lista "Todas"
    Cuando escribo "Leer capítulo 10" en "Nueva tarea" y presiono Enter
    Entonces la tarea aparece primera en la lista y el campo queda vacío con el foco

  Esquema del escenario: CA-FE-02 Atajos de fecha y materia
    Dado que hoy es miércoles 14 de octubre de 2026
    Cuando escribo <texto> y presiono Enter
    Entonces se crea la tarea <titulo> con vencimiento <vence> y materia <materia>

    Ejemplos:
      | texto                         | titulo              | vence          | materia          |
      | Práctica 3 mañana #est2       | Práctica 3          | jue 15 oct     | Estadística II   |
      | Informe de normalización #bd2 | Informe de normalización |           | Base de Datos II |
      | Repasar jueves                | Repasar             | jue 15 oct     |                  |

  Escenario: CA-FE-03 Título vacío
    Cuando presiono Enter con el campo vacío
    Entonces no se crea ninguna tarea
```
