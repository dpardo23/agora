# HU-16.03 · Recibir notificaciones push

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **estudiante**, quiero **recibir notificaciones en el teléfono cuando un esquema espera mi aprobación, un documento se entrega, termina un pomodoro o llega un recordatorio**, para **reaccionar a tiempo sin tener la app abierta**. |
| **Contexto** | Web Push con claves VAPID. |
| **Reglas de negocio** | RN-1: tipos: esquema pendiente, trabajo entregado, error del Olimpo, recordatorio de evento o tarea y fin de pomodoro. · RN-2: el permiso se pide **después de una acción del usuario** (interruptor «Notificaciones» en Configuración), nunca al cargar. · RN-3: cada tipo se puede activar o desactivar. · RN-4: tocar la notificación abre la pantalla correspondiente (p. ej. el esquema). · RN-5: el texto no incluye contenido sensible (solo el título del documento y la materia). |
| **Datos** | `suscripciones_push(id, endpoint, claves, tipos, dispositivo_id)`. |
| **Supuestos** | iOS 16.4+ solo admite push con la PWA instalada. |
| **Fuera de alcance** | |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Recibir notificaciones push

  Escenario: CA-FE-01 Activar
    Cuando activo "Notificaciones" en Configuración y acepto el permiso del sistema
    Entonces veo los tipos activados por defecto

  Escenario: CA-FE-02 Esquema pendiente
    Dado las notificaciones activas
    Cuando el #18 queda esperando aprobación
    Entonces recibo "Esquema listo para revisar · #18 Base de Datos II"
    Y al tocarla se abre "Esquema propuesto" del #18

  Escenario: CA-FE-03 Tipo desactivado
    Dado que desactivé "Fin de pomodoro"
    Cuando termina un bloque
    Entonces no llega ninguna notificación push de ese tipo
```
