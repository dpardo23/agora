# HU-16.02 · Abrir pantallas y documentos sin conexión

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **estudiante**, quiero **abrir la app y los PDF que ya consulté aunque no tenga internet**, para **estudiar en el micro o en un aula sin señal**. |
| **Contexto** | Estrategias de caché del service worker. |
| **Reglas de negocio** | RN-1: precache del shell (layout, rutas y fuentes). · RN-2: `NetworkFirst` para datos, con respaldo en caché; `CacheFirst` para fuentes e imágenes. · RN-3: los PDF abiertos al menos una vez quedan disponibles sin conexión (máximo 30, se descartan los más antiguos). · RN-4: sin conexión se muestra la franja «Sin conexión · mostrando lo último guardado» y se deshabilitan las acciones que requieren red (encargar, aprobar), con el motivo. · RN-5: al cerrar sesión se borra la caché privada (HU-03.05). |
| **Datos** | Cache Storage del service worker. |
| **Supuestos** | |
| **Fuera de alcance** | Edición sin conexión, salvo repaso (HU-14.01) y tareas rápidas (HU-12.01). |
