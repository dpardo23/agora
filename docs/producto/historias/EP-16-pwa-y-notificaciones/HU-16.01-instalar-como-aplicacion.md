# HU-16.01 · Instalar la plataforma como aplicación

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **estudiante**, quiero **instalar dpardo en mi teléfono y en mi PC como una app**, para **abrirla desde el inicio sin buscar la pestaña del navegador**. |
| **Contexto** | PWA con manifest y service worker (Serwist (`@serwist/next`)). |
| **Reglas de negocio** | RN-1: manifest con nombre «dpardo», `display: standalone`, `start_url: /`, `theme_color` según el tema e iconos 192, 512 y maskable. · RN-2: el sistema operativo ofrece instalar; además, Configuración muestra «Instalar app» cuando el navegador lo permite (`beforeinstallprompt`). · RN-3: en iOS se muestra una ayuda («Compartir → Agregar a inicio»). · RN-4: al publicar una versión nueva, aparece el toast «Hay una versión nueva» con «Actualizar». |
| **Datos** | |
| **Supuestos** | |
| **Fuera de alcance** | Uso sin conexión (HU-16.02). |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Instalar como aplicación
```
