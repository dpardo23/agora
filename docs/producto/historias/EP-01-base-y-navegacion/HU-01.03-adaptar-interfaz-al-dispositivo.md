# HU-01.03 · Usar la plataforma en móvil, tablet y escritorio

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **estudiante**, quiero **que cada pantalla se adapte al ancho de mi dispositivo**, para **usar la plataforma igual de bien en el PC, en una tablet o en el teléfono**. |
| **Contexto** | El diseño trae dos artboards por pantalla (1440 px y 390 px). La tablet no está dibujada. |
| **Reglas de negocio** | RN-1: breakpoints: móvil < 768 px, tablet de 768 a 1199 px, escritorio ≥ 1200 px. · RN-2: en tablet, la sidebar se colapsa a iconos de 64 px, con tooltip con el nombre. · RN-3: nunca hay scroll horizontal de página entre 320 y 2560 px. · RN-4: el contenido usa columnas flex que envuelven, no `grid-column: span` en grids `auto-fit`. · RN-5: tamaño base de 14 px en escritorio y 15 px en filas táctiles de móvil. |
| **Datos** | |
| **Supuestos** | El zoom del navegador al 200 % equivale, a efectos de reflow, al breakpoint inferior. |
| **Fuera de alcance** | Orientación horizontal específica del móvil. |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Usar la plataforma en móvil, tablet y escritorio

  Esquema del escenario: CA-FE-01 Navegación según el ancho
    Dado que abro "/" con una ventana de <ancho> px
    Entonces veo <navegacion>

    Ejemplos:
      | ancho | navegacion                                   |
      | 390   | la barra inferior y la cabecera con campana  |
      | 834   | la sidebar colapsada a iconos                |
      | 1440  | la sidebar completa de 232 px                |

  Escenario: CA-FE-02 Tooltip en la sidebar colapsada
    Dado que la ventana mide 834 px
    Cuando paso el puntero o pongo el foco en el icono de Materias
    Entonces aparece el tooltip "Materias"

  Escenario: CA-FE-03 Redimensionar sin perder la ruta
    Dado que estoy en "/agenda/horario" a 1440 px
    Cuando reduzco la ventana a 390 px
    Entonces sigo en "/agenda/horario" y la barra inferior marca "Agenda"
```
