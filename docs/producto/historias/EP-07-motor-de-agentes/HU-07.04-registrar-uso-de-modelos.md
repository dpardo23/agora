# HU-07.04 · Registrar el uso de modelos en cada llamada

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **dueño del Olimpo**, quiero **que cada llamada a Claude o a Gemini quede registrada con sus tokens y su costo equivalente**, para **poder medir el consumo del Olimpo y decidir qué pasos mover a Gemini**. |
| **Contexto** | Sustituye a `datos/uso.jsonl` del Olimpo actual. Alimenta la pestaña Consumo (EP-08) y el estimado del encargo. |
| **Reglas de negocio** | RN-1: una fila en `uso_modelo` por llamada: `trabajo_id`, `paso`, `agente_id`, `motor`, `modelo`, `tokens_in`, `tokens_out`, `usd_lista`, `origen` (`olimpo` o `interactivo`) y `creado_en`. · RN-2: `usd_lista` se calcula con la tabla de precios de lista versionada en `precios_modelo`. · RN-3: los pasos de Python, TeX Live y Drive no generan filas de modelo. · RN-4: si la inserción falla, se guarda en un archivo local y se reenvía después (no se pierde el registro). |
| **Datos** | `uso_modelo`, `precios_modelo(modelo, vigente_desde, usd_in_mtok, usd_out_mtok)`. |
| **Supuestos** | |
| **Fuera de alcance** | Mostrar el consumo (EP-08). |
