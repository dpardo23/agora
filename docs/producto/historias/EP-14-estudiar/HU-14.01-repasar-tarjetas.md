# HU-14.01 · Repasar tarjetas con repetición espaciada

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **estudiante**, quiero **repasar cada día las tarjetas que tocan y calificar cuánto recordé**, para **retener lo que estudio con el menor tiempo posible**. |
| **Contexto** | `/estudiar` (pestaña Repaso). Las tarjetas las genera Mnemósine (Tutora) de cada documento (HU-14.02). |
| **Reglas de negocio** | RN-1: indicadores: «{n} para hoy», «{d} días seguidos» (racha) y «{x} % retención». · RN-2: tabla de mazos: «Mazo · Venc. · Hoy · Nuevas». · RN-3: sesión: «{materia} · sesión», «{pos} / {total}», tipo y origen de la tarjeta, pregunta; «Mostrar respuesta» (atajo **Espacio**). · RN-4: calificaciones «Otra vez», «Difícil», «Bien» y «Fácil», con el intervalo que resulta de FSRS debajo de cada una (p. ej. «< 10 min · 1 d · 3 d · 8 d»); atajos 1 a 4. · RN-5: la programación usa `ts-fsrs` con los parámetros por defecto. · RN-6: la racha cuenta días (en La Paz) con al menos una revisión. · RN-7: al terminar, resumen («24 tarjetas · 18 min · 83 % Bien o Fácil»). · RN-8: en móvil, filtros de mazo en chips («Estadística II · 24 · BD II · 14 · Ec. Dif. · 3»). |
| **Datos** | `mazos`, `tarjetas(id, mazo_id, tipo, origen, pregunta, respuesta, fsrs jsonb, vence_en)`, `revisiones(tarjeta_id, calificacion, revisado_en, intervalo)`. |
| **Supuestos** | |
| **Fuera de alcance** | Edición manual de tarjetas. |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Repasar tarjetas

  Escenario: CA-FE-01 Ver lo que toca hoy
    Dado 24 tarjetas vencidas para hoy
    Cuando abro "/estudiar"
    Entonces veo "24 para hoy", "12 días seguidos" y "87 % retención"

  Escenario: CA-FE-02 Mostrar la respuesta con Espacio
    Dado una tarjeta en pantalla
    Cuando presiono Espacio
    Entonces aparece "Respuesta" con su texto y las 4 calificaciones con sus intervalos

  Escenario: CA-FE-03 Calificar con el teclado
    Cuando presiono 3 ("Bien")
    Entonces la tarjeta se reprograma según FSRS y pasa la siguiente ("2 / 24")

  Escenario: CA-FE-04 Fin de la sesión
    Cuando califico la última tarjeta
    Entonces veo el resumen con la cantidad, el tiempo y el porcentaje de Bien o Fácil

  Escenario: CA-FE-05 Nada para hoy
    Dado 0 tarjetas vencidas
    Entonces veo "No hay tarjetas para hoy" y la próxima fecha con vencimientos
```
