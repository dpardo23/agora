# HU-06.03 · Consultar el registro en vivo del Olimpo

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **dueño del Olimpo**, quiero **leer en una lista con hora lo que va haciendo cada dios**, para **entender el detalle de lo que pasa y detectar problemas a tiempo**. |
| **Contexto** | Bloque «Registro en vivo» bajo el pipeline. |
| **Reglas de negocio** | RN-1: cada línea: hora `HH:mm:ss` (La Paz), nombre del dios y mensaje, en Geist Mono. · RN-2: lo más reciente va **abajo**, con scroll automático solo si el usuario ya estaba al final. · RN-3: se muestran las últimas 100 líneas; «Ver más» carga las 100 anteriores. · RN-4: las líneas de error van en `--warn`. · RN-5: si el usuario se desplazó hacia arriba y llegan líneas nuevas, aparece el botón «{n} nuevas ↓». |
| **Datos** | `eventos_agente` con `mensaje` no nulo. |
| **Supuestos** | |
| **Fuera de alcance** | Exportar el registro. |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Consultar el registro en vivo

  Escenario: CA-FE-01 Líneas con hora y dios
    Entonces veo "13:58:02 Apolo sección 3.1 «Dependencias funcionales» redactada"

  Escenario: CA-FE-02 Nueva línea al final
    Dado que estoy al final del registro
    Cuando llega un evento con el mensaje "entrega la figura 1 al Maquetador"
    Entonces la línea aparece abajo y el registro se desplaza para mostrarla

  Escenario: CA-FE-03 No interrumpir la lectura
    Dado que me desplacé hacia arriba
    Cuando llegan 3 eventos
    Entonces el registro no se mueve y aparece "3 nuevas ↓"

  Escenario: CA-FE-04 Línea de error
    Cuando llega un "paso_fallido"
    Entonces su línea se muestra en color --warn
```
