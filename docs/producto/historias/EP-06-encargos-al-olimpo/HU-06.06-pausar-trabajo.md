# HU-06.06 · Pausar y reanudar un trabajo en curso

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **dueño del Olimpo**, quiero **pausar el trabajo activo y reanudarlo después**, para **liberar cupo cuando lo necesito para otra cosa**. |
| **Contexto** | Botón «Pausar trabajo» en la cabecera del trabajo activo. |
| **Reglas de negocio** | RN-1: pausar cambia `trabajos.estado_control = 'pausado'`; el worker termina el paso actual y no inicia el siguiente. · RN-2: el botón pasa a «Reanudar trabajo» y la etiqueta del trabajo a «Pausado». · RN-3: mientras está pausado, el siguiente trabajo de la cola **no** se adelanta (la cola es FIFO), salvo que el usuario lo elija con «Atender el siguiente». · RN-4: los dioses de un trabajo pausado pasan a `libre` y van al Salón de Dioniso. |
| **Datos** | `trabajos.estado_control`. |
| **Supuestos** | |
| **Fuera de alcance** | Cancelar definitivamente un trabajo en proceso. |
