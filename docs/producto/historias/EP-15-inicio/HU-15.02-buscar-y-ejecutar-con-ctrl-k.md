# HU-15.02 · Buscar y ejecutar acciones con Ctrl K

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **estudiante**, quiero **abrir una paleta con Ctrl K y escribir lo que busco o lo que quiero hacer**, para **llegar a cualquier pantalla, materia, tarea o acción sin usar el mouse**. |
| **Contexto** | Paleta global, disponible desde cualquier pantalla (`Dialogos`). |
| **Reglas de negocio** | RN-1: se abre con Ctrl K (⌘ K en macOS) o desde «Buscar o ejecutar…». · RN-2: resultados agrupados: Acciones (Nueva tarea, Nuevo evento, Encargar al Olimpo, Iniciar pomodoro), Navegación (las 17 rutas), Materias, Tareas y Documentos. · RN-3: búsqueda difusa sin distinguir tildes. · RN-4: teclado: «↑ ↓ moverse · Enter abrir · Esc cerrar». · RN-5: sin resultados: «Sin resultados. Enter para encargar «{texto}» al Olimpo.»; Enter abre el encargo con ese tema. · RN-6: muestra primero las 5 acciones usadas más recientemente. |
| **Datos** | Índice en memoria de rutas y acciones + búsqueda en `materias`, `tareas` y `trabajos`. |
| **Supuestos** | |
| **Fuera de alcance** | |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Buscar y ejecutar con Ctrl K

  Escenario: CA-FE-01 Abrir desde cualquier pantalla
    Dado que estoy en "/tareas"
    Cuando presiono Ctrl K
    Entonces se abre la paleta con el foco en "Buscar o ejecutar"

  Escenario: CA-FE-02 Navegar
    Cuando escribo "malla" y presiono Enter
    Entonces llego a "/materias/malla"

  Escenario: CA-FE-03 Encargar sin resultados
    Cuando escribo "teorema de bayes" y no hay resultados
    Entonces veo "Sin resultados. Enter para encargar «teorema de bayes» al Olimpo."
    Y al presionar Enter se abre el encargo con ese tema

  Escenario: CA-FE-04 Sin tildes
    Cuando escribo "estadistica"
    Entonces aparece la materia "Estadística II"
```
