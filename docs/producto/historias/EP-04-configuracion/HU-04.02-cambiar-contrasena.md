# HU-04.02 · Cambiar la contraseña con verificación por Gmail

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **titular de la cuenta**, quiero **cambiar mi contraseña confirmándolo con un código de Gmail**, para **que nadie con mi sesión abierta pueda cambiarla sin mi correo**. |
| **Contexto** | Bloque «Cambiar contraseña» de Configuración, en 3 pasos: «01 Nueva contraseña · 02 Código de Gmail · 03 Listo». |
| **Reglas de negocio** | RN-1: paso 1: contraseña actual, nueva y confirmación; barra de fuerza con las 4 reglas («Mínimo 8 caracteres», «Una mayúscula», «Una minúscula», «Un carácter especial»). · RN-2: «Enviar código a Gmail» se habilita solo con 4/4 reglas y la confirmación igual («Las contraseñas coinciden» / «No coinciden todavía»). · RN-3: paso 2: `auth.reauthenticate()` envía el código; `updateUser({ password, nonce })` lo aplica («Secure password change» activado en Supabase). · RN-4: paso 3: «Contraseña actualizada» · «Se cerró la sesión en tus otros dispositivos.» (`signOut({ scope: 'others' })`). · RN-5: la nueva contraseña no puede ser igual a la actual. |
| **Datos** | `actual`, `nueva`, `confirmacion`, `nonce`. |
| **Supuestos** | |
| **Fuera de alcance** | Recuperación sin sesión (HU-03.04). |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Cambiar la contraseña

  Esquema del escenario: CA-FE-01 Reglas cumplidas en vivo
    Cuando escribo <nueva> en "Nueva contraseña"
    Entonces la barra muestra "<n>/4" y las reglas cumplidas llevan su marca

    Ejemplos:
      | nueva     | n |
      | umss      | 1 |
      | umss2026  | 2 |
      | Umss2026  | 3 |
      | Umss2026! | 4 |

  Escenario: CA-FE-02 Confirmación distinta
    Cuando la confirmación no coincide
    Entonces veo "No coinciden todavía" y "Enviar código a Gmail" está deshabilitado

  Escenario: CA-FE-03 Enviar el código
    Dado 4/4 reglas y "Las contraseñas coinciden"
    Cuando hago clic en "Enviar código a Gmail"
    Entonces paso a "Revisa tu Gmail" con "Enviamos un código de 6 dígitos a jdiego•••@gmail.com. Vence en 10 minutos."

  Escenario: CA-FE-04 Verificar y cambiar
    Cuando escribo el código correcto y hago clic en "Verificar y cambiar"
    Entonces veo "Contraseña actualizada" y "Se cerró la sesión en tus otros dispositivos."

  Escenario: CA-FE-05 Contraseña actual incorrecta
    Cuando la contraseña actual no es la correcta
    Entonces veo "La contraseña actual no es correcta." y no se envía ningún código

  Escenario: CA-FE-06 Volver al paso 1
    Dado que estoy en el paso 2
    Cuando hago clic en "Volver"
    Entonces regreso al paso 1 con los campos de contraseña vacíos
```

## 3. Criterios de aceptación no funcionales (CA-NF)
