# HU-04.03 · Gestionar las sesiones activas y la verificación en dos pasos

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **titular de la cuenta**, quiero **ver en qué dispositivos tengo sesión, cerrar los que no reconozco y ajustar la verificación en dos pasos**, para **mantener el control de quién entra a mi cuenta**. |
| **Contexto** | Bloque «Verificación en dos pasos» y «Sesiones activas» de Configuración. |
| **Reglas de negocio** | RN-1: la lista muestra cada dispositivo confiable con su etiqueta y su último uso; el actual va primero, marcado «Este PC» o «Este teléfono». · RN-2: «Cerrar las demás» revoca todas las sesiones y dispositivos confiables excepto el actual. · RN-3: el interruptor «Pedir código por Gmail» viene **activado** y no se puede desactivar sin confirmar con la contraseña. · RN-4: «Recordar este dispositivo 30 días» es solo informativo. · RN-5: la sección «Cuenta» muestra el usuario y el correo **enmascarado**. |
| **Datos** | `dispositivos_confiables`, `perfil.usuario`, `perfil.correo_verificacion`, `perfil.dos_pasos`. |
| **Supuestos** | |
| **Fuera de alcance** | Cambiar el usuario o el correo (no está en el diseño). |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Gestionar sesiones y verificación

  Escenario: CA-FE-01 Ver mis sesiones
    Dado que tengo sesión en este PC y en Android (PWA)
    Cuando abro "/configuracion"
    Entonces veo "Sesiones activas" con "Este PC · Android (PWA)"

  Escenario: CA-FE-02 Cerrar las demás sesiones
    Cuando hago clic en "Cerrar las demás" y confirmo
    Entonces solo queda "Este PC"
    Y el teléfono debe iniciar sesión y verificar el código otra vez

  Escenario: CA-FE-03 Desactivar el código requiere la contraseña
    Cuando desactivo "Pedir código por Gmail"
    Entonces se me pide la contraseña actual
    Y si la cancelo, el interruptor vuelve a activado

  Escenario: CA-FE-04 Datos de la cuenta enmascarados
    Entonces en "Cuenta" veo "Usuario: dpardo" y "Correo para verificación: jdiego•••@gmail.com"
```
