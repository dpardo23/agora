# HU-04.01 · Guardar la preferencia de tema en mi perfil

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **titular de la cuenta**, quiero **que el tema que elijo se aplique en todos mis dispositivos**, para **no tener que configurarlo en cada uno**. |
| **Contexto** | HU-01.02 guarda el tema solo en el navegador. Aquí pasa a `perfil.tema`. |
| **Reglas de negocio** | RN-1: al cambiar el tema se guarda en `perfil.tema` y en `localStorage` (este último evita el parpadeo). · RN-2: al iniciar sesión, si `perfil.tema` difiere de `localStorage`, gana el perfil y se actualiza `localStorage`. · RN-3: si el guardado falla, el tema igual cambia en la sesión y se muestra un toast de error con «Reintentar». |
| **Datos** | `perfil.tema` ∈ {`claro`, `oscuro`, `sistema`}. |
| **Supuestos** | |
| **Fuera de alcance** | |
