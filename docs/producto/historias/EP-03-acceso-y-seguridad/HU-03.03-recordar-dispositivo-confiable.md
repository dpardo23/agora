# HU-03.03 · Recordar un dispositivo de confianza durante 30 días

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **titular de la cuenta**, quiero **que mi PC y mi teléfono no me pidan el código de Gmail en cada inicio de sesión**, para **entrar rápido sin perder la protección en dispositivos ajenos**. |
| **Contexto** | La casilla «Recordar este dispositivo» del login decide si, tras verificar el código, el dispositivo queda como confiable. |
| **Reglas de negocio** | RN-1: si la casilla está marcada al verificar, se registra el dispositivo en `dispositivos_confiables` con vencimiento a **30 días** y se fija la cookie `dpardo_device`. · RN-2: si no está marcada, la próxima vez se pide el código de nuevo. · RN-3: el dispositivo guarda una etiqueta legible (p. ej. «Este PC · Linux · Chromium», «Android (PWA)») derivada del user agent. · RN-4: a los 30 días, o si se revoca desde Configuración (HU-04.03), vuelve a pedirse el código. · RN-5: la casilla viene **marcada** por defecto, como en el diseño. |
| **Datos** | `dispositivos_confiables(id, user_id, token_hash, etiqueta, creado_en, ultimo_uso, vence_en, revocado_en)`. |
| **Supuestos** | |
| **Fuera de alcance** | La lista y la revocación de dispositivos (HU-04.03). |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Recordar un dispositivo de confianza

  Escenario: CA-FE-01 Recordar al verificar
    Dado que en "/login" dejo marcada "Recordar este dispositivo"
    Y que verifico el código de Gmail
    Cuando cierro sesión y vuelvo a entrar con usuario y contraseña
    Entonces entro directo a "/" sin el paso "Revisa tu Gmail"

  Escenario: CA-FE-02 No recordar
    Dado que desmarqué "Recordar este dispositivo" antes de verificar
    Cuando cierro sesión y vuelvo a entrar
    Entonces se me pide de nuevo el código de Gmail

  Escenario: CA-FE-03 Vencimiento a los 30 días
    Dado un dispositivo confiable registrado hace 31 días
    Cuando inicio sesión
    Entonces se me pide el código de Gmail

  Escenario: CA-FE-04 Cookie manipulada
    Dado que la cookie "dpardo_device" fue alterada
    Cuando inicio sesión
    Entonces se trata como un dispositivo nuevo y se pide el código
```

## 3. Criterios de aceptación no funcionales (CA-NF)
