# HU-03.05 · Cerrar sesión en este dispositivo o en todos

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **titular de la cuenta**, quiero **cerrar la sesión en este dispositivo y, si quiero, en todos los demás**, para **proteger mi cuenta cuando uso un equipo prestado o pierdo el teléfono**. |
| **Contexto** | Se dispara desde «Cerrar sesión» en Configuración (escritorio y móvil). |
| **Reglas de negocio** | RN-1: siempre pide confirmación con el diálogo «¿Cerrar sesión en este PC?» (en móvil, «en este teléfono»). · RN-2: la casilla «Cerrar también en los demás dispositivos» viene desmarcada. · RN-3: el Olimpo sigue trabajando en la VM; cerrar sesión no cancela trabajos. · RN-4: cerrar sesión no revoca el dispositivo confiable de este equipo, salvo que se marque la casilla. · RN-5: tras cerrar, se borran los datos en caché de la PWA que sean privados (consultas y PDF). |
| **Datos** | `signOut({ scope: 'local' \| 'global' })`. |
| **Supuestos** | |
| **Fuera de alcance** | La lista de sesiones (HU-04.03). |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Cerrar sesión

  Escenario: CA-FE-01 Confirmar el cierre en este dispositivo
    Dado que estoy en "/configuracion"
    Cuando hago clic en "Cerrar sesión"
    Entonces se abre "¿Cerrar sesión en este PC?"
    Y el texto dice "El Olimpo sigue trabajando en la VM. Para volver a entrar necesitas usuario, contraseña y el código de Gmail si no recordaste el dispositivo."

  Escenario: CA-FE-02 Cerrar solo aquí
    Cuando confirmo con "Cerrar sesión" sin marcar la casilla
    Entonces llego a "/login"
    Y la sesión de mi teléfono sigue activa

  Escenario: CA-FE-03 Cerrar en todos los dispositivos
    Cuando marco "Cerrar también en los demás dispositivos" y confirmo
    Entonces llego a "/login"
    Y al usar el teléfono se le pide iniciar sesión

  Escenario: CA-FE-04 Cancelar
    Cuando hago clic en "Cancelar"
    Entonces el diálogo se cierra y sigo con sesión

  Escenario: CA-FE-05 Volver atrás después de cerrar
    Dado que cerré sesión
    Cuando uso el botón Atrás del navegador
    Entonces no veo datos privados y me lleva a "/login"
```

## 3. Criterios de aceptación no funcionales (CA-NF)

| ID | Atributo | Verificar | Condición | Resultado esperado |
|---|---|---|---|---|
| CA-NF-01 | Seguridad | Caché tras cerrar | Service worker y almacenamiento | Sin respuestas privadas en Cache Storage ni en IndexedDB |
| CA-NF-02 | Seguridad | Token tras el cierre global | Petición con el token anterior | HTTP 401 |
