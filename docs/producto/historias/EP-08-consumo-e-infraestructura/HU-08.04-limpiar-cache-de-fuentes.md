# HU-08.04 · Limpiar la caché de fuentes de la VM

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **dueño del Olimpo**, quiero **liberar el disco borrando las fuentes descargadas que ya no se usan**, para **que la VM no se llene**. |
| **Contexto** | Botón «Limpiar caché de fuentes» en el bloque del servidor. |
| **Reglas de negocio** | RN-1: pide confirmación con el espacio estimado: «Se liberarán ≈ {x} GB. Las fuentes de trabajos en curso no se tocan.». · RN-2: la web inserta una orden en `ordenes_vm` (`limpiar_cache_fuentes`); el worker la ejecuta y responde. · RN-3: no borra fuentes de trabajos `en_cola`, `en_proceso` ni `esperando_aprobacion`. · RN-4: al terminar, toast «Se liberaron {x} GB» y el disco se actualiza. |
| **Datos** | `ordenes_vm(id, tipo, estado, resultado)`. |
| **Supuestos** | |
| **Fuera de alcance** | Otras órdenes remotas. |
