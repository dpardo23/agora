# HU-13.02 · Convertir un aviso en tarea o aplicar el dato detectado

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **estudiante**, quiero **crear una tarea desde un aviso o aplicar con un clic el cambio de fecha o de aula que el Olimpo detectó**, para **actualizar mi organización sin copiar datos a mano**. |
| **Contexto** | Bloque «Detectado automáticamente» del detalle del aviso. |
| **Reglas de negocio** | RN-1: Hermes extrae, si existen, fecha, aula y materia; se muestran como chips en «Detectado automáticamente». · RN-2: acción sugerida según lo detectado: cambio de aula → «Aplicar al horario»; fecha de entrega → «Crear tarea con fecha»; fecha de examen → «Crear evento». · RN-3: «Crear tarea» abre «Nueva tarea» con título, materia y vencimiento precargados, y un enlace al aviso. · RN-4: aplicar un cambio de aula pide confirmar el rango («Solo la próxima clase» o «Desde ahora») y actualiza el horario. · RN-5: lo aplicado se marca en el aviso («Aplicado al horario · 14:20»). |
| **Datos** | `avisos.detectado`, `avisos.aplicado_en`. |
| **Supuestos** | |
| **Fuera de alcance** | |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Convertir un aviso en acción

  Escenario: CA-FE-01 Crear tarea precargada
    Dado un aviso de "Base de Datos II" con la fecha detectada "viernes 23 de octubre"
    Cuando hago clic en "Crear tarea"
    Entonces se abre "Nueva tarea" con la materia "Base de Datos II" y vence "viernes 23 oct"

  Escenario: CA-FE-02 Aplicar un cambio de aula
    Dado un aviso con el aula detectada "690B" para "Base de Datos II"
    Cuando hago clic en "Aplicar al horario" y elijo "Desde ahora"
    Entonces el horario muestra "690B" en las próximas clases
    Y el aviso dice "Aplicado al horario"

  Escenario: CA-FE-03 Sin datos detectados
    Dado un aviso sin fecha, aula ni materia reconocibles
    Entonces no se muestra el bloque "Detectado automáticamente"
```
