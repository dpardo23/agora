# HU-11.03 · Consultar el horario semanal de clases

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **estudiante**, quiero **ver mi horario de lunes a sábado con el tipo de clase y el aula**, para **saber dónde tengo que estar en cada momento**. |
| **Contexto** | `/agenda/horario`. |
| **Reglas de negocio** | RN-1: rejilla de L a S con franjas horarias; cada bloque muestra la materia, la hora, el tipo y el aula. · RN-2: **Teoría** = bloque relleno con el pastel de la materia; **Laboratorio** = rayado; **Auxiliatura** = borde discontinuo (además del texto del tipo). · RN-3: cabecera «Gestión II/2026 · semana del {d} al {d} de {mes}». · RN-4: panel «Siguiente clase · {cuándo}» con hora, materia, tipo, aula y docente. · RN-5: «Horas por semana · {total} h» con el desglose por materia. · RN-6: «Los cambios de aula detectados en Avisos se aplican aquí con un clic.» (HU-13.02). · RN-7: en móvil, selector de día («L M M J V S») y la lista de bloques del día; si no hay clases, «Sin clases este día». |
| **Datos** | `materia_horarios(materia_id, dia, inicio, fin, aula, tipo)`. |
| **Supuestos** | |
| **Fuera de alcance** | Editar el horario (se hace desde la materia, HU-09.04) y exportar (HU-11.04). |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Consultar el horario semanal

  Escenario: CA-FE-01 Ver los bloques
    Dado "Base de Datos II" con Teoría el lunes de 09:45 a 11:15
    Cuando abro "/agenda/horario"
    Entonces veo el bloque relleno de color cielo el lunes con "Base de Datos II", "09:45 – 11:15" y "Teoría"

  Escenario: CA-FE-02 Siguiente clase
    Dado que hoy es martes a las 20:00 y mañana a las 07:45 tengo "Base de Datos II"
    Entonces veo "Siguiente clase · mañana" con "07:45" y "Base de Datos II"

  Escenario: CA-FE-03 Distinción por tipo
    Entonces los laboratorios se ven rayados y las auxiliaturas con borde discontinuo

  Escenario: CA-FE-04 Día sin clases en móvil
    Dado una ventana de 390 px
    Cuando elijo el sábado y no hay clases
    Entonces veo "Sin clases este día"
```
