# HU-11.04 · Exportar el horario y los eventos a Google Calendar

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **estudiante**, quiero **enviar mi horario y mis eventos a Google Calendar o descargarlos como .ics**, para **verlos en el calendario del teléfono junto con el resto de mi vida**. |
| **Contexto** | Diálogo «Exportar horario y eventos» desde «Exportar a Google Calendar». |
| **Reglas de negocio** | RN-1: «Calendario destino» («UMSS (nuevo)» o uno existente). · RN-2: «Rango» («Toda la gestión II/2026», «Este mes», «Esta semana»). · RN-3: «Incluir»: Clases (horario semanal), Parciales, Entregas y Sesiones de estudio. · RN-4: resumen «Se crearán [N] eventos y se mantendrán sincronizados.» con el número real. · RN-5: «Exportar» los crea vía n8n; «Descargar .ics» genera el archivo sin conectar Google. · RN-6: exportar dos veces no duplica (se usa un id externo). |
| **Datos** | `eventos.google_event_id`. |
| **Supuestos** | |
| **Fuera de alcance** | Importar desde Google Calendar. |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Exportar a Google Calendar

  Escenario: CA-FE-01 Resumen con el número real
    Dado 4 materias con 9 bloques semanales y 6 parciales en la gestión
    Cuando incluyo Clases y Parciales para "Toda la gestión II/2026"
    Entonces el resumen muestra el número exacto de eventos a crear

  Escenario: CA-FE-02 Exportar sin duplicar
    Dado que ya exporté la gestión
    Cuando exporto de nuevo
    Entonces no se crean eventos duplicados en Google Calendar

  Escenario: CA-FE-03 Descargar .ics
    Cuando hago clic en "Descargar .ics"
    Entonces se descarga un archivo .ics válido con los eventos elegidos
```
