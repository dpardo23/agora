# HU-10.01 · Consultar la malla curricular con el estado de cada materia

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **estudiante**, quiero **ver mi plan de estudios por semestres con el estado de cada materia**, para **saber cuánto avancé en la carrera**. |
| **Contexto** | `/materias/malla`. Mientras no se importe el plan oficial (HU-10.03), se usa el plan de ejemplo marcado como tal: «Ingeniería de Sistemas · plan de ejemplo». |
| **Reglas de negocio** | RN-1: semestres en columnas («S1» … «S10») con «{hechas}/{total}». · RN-2: estados: **aprobada**, **cursando**, **disponible** (prerrequisitos aprobados) y **bloqueada**; el estado de disponible y bloqueada se **calcula**, no se guarda. · RN-3: el estado se distingue por color **y** por un patrón o icono (no solo por color). · RN-4: resumen «{aprobadas}/{total} · {pct} %» y contadores por estado. · RN-5: en móvil, los semestres se recorren con un desplazamiento horizontal por tarjetas («S{n}»). · RN-6: una materia «Cursando» en Mis materias aparece como cursando en la malla. |
| **Datos** | `plan_materias(codigo, nombre, semestre)`, `plan_prerrequisitos`, `materias.estado`. |
| **Supuestos** | |
| **Fuera de alcance** | Detalle de prerrequisitos (HU-10.02). |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Consultar la malla

  Escenario: CA-FE-01 Ver la malla
    Dado 13 materias aprobadas de 24
    Cuando abro "/materias/malla"
    Entonces veo "13/24 · 54 %" y los semestres en columnas

  Esquema del escenario: CA-FE-02 Estado calculado
    Dado una materia cuyos prerrequisitos están <prerrequisitos>
    Y que no está aprobada ni cursando
    Entonces se muestra como <estado>

    Ejemplos:
      | prerrequisitos   | estado      |
      | todos aprobados  | Disponible  |
      | uno sin aprobar  | Bloqueada   |

  Escenario: CA-FE-03 Plan de ejemplo marcado
    Dado que no importé el plan oficial
    Entonces veo "Ingeniería de Sistemas · plan de ejemplo"
```
