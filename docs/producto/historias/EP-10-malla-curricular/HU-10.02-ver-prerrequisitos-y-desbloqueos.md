# HU-10.02 · Ver los prerrequisitos y lo que desbloquea una materia

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **estudiante**, quiero **seleccionar una materia de la malla y ver qué necesito para cursarla y qué me abre**, para **planificar qué inscribir la próxima gestión**. |
| **Contexto** | Panel de detalle de la malla (en móvil, tarjeta inferior). |
| **Reglas de negocio** | RN-1: al seleccionar, se **resaltan** en la grilla sus prerrequisitos y las materias que desbloquea; el resto se atenúa. · RN-2: el panel muestra «Semestre {n} · {estado}», nombre, «Prerrequisitos» (con el estado de cada uno o «Ninguno») y «Desbloquea» (o «Ninguna en este tramo»). · RN-3: mensaje: si está bloqueada, «Te falta aprobar {lista}»; si está disponible, «Puedes inscribirla». · RN-4: Esc o un clic fuera quitan la selección. |
| **Datos** | `plan_prerrequisitos`, `v_malla`. |
| **Supuestos** | |
| **Fuera de alcance** | |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Ver prerrequisitos y desbloqueos

  Escenario: CA-FE-01 Materia bloqueada
    Dado que "Taller de Base de Datos" requiere "Base de Datos II", que estoy cursando
    Cuando la selecciono
    Entonces veo "Te falta aprobar Base de Datos II"
    Y "Base de Datos II" se resalta en la grilla

  Escenario: CA-FE-02 Materia disponible
    Cuando selecciono una materia con todos sus prerrequisitos aprobados
    Entonces veo "Puedes inscribirla"

  Escenario: CA-FE-03 Sin prerrequisitos
    Cuando selecciono una materia de S1
    Entonces en "Prerrequisitos" veo "Ninguno"

  Escenario: CA-FE-04 Quitar la selección
    Cuando presiono Esc
    Entonces ninguna materia queda resaltada
```
