# HU-02.06 · Abrir diálogos como modal o como hoja inferior según el dispositivo

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **estudiante**, quiero **que los diálogos se abran centrados en el PC y desde abajo en el teléfono**, para **completarlos cómodamente con el mouse o con el pulgar**. |
| **Contexto** | Diálogos del diseño: revisar esquema, nueva tarea, nuevo evento, configurar agente, reglas, importar plan, exportar a Calendar, cerrar sesión, eliminar materia, recuperar contraseña y confirmación de pausa. |
| **Reglas de negocio** | RN-1: un solo componente `ResponsiveDialog` (Dialog en escritorio, Drawer en móvil): **modal** a partir de 768 px y **hoja inferior** por debajo. · RN-2: el foco queda atrapado dentro y vuelve al disparador al cerrar. · RN-3: se cierra con «×», Esc, «Cancelar» o tocando el velo; la hoja también se cierra **deslizando hacia abajo** más de 30 % de su alto. · RN-4: si el formulario tiene cambios sin guardar, al cerrar se pide confirmación («¿Descartar cambios?»). · RN-5: variante **destructiva**: el botón de peligro solo se habilita al escribir el texto de confirmación exacto. · RN-6: el fondo no hace scroll mientras el diálogo está abierto. |
| **Datos** | Props: `titulo`, `descripcion`, `destructivo`, `textoConfirmacion`, `sucio`. |
| **Supuestos** | |
| **Fuera de alcance** | El contenido de cada diálogo (en sus HU). |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Abrir diálogos adaptables

  Escenario: CA-FE-01 Modal en escritorio
    Dado una ventana de 1440 px
    Cuando hago clic en "+ Tarea"
    Entonces se abre el modal "Nueva tarea" centrado sobre el velo
    Y el foco está en el primer campo

  Escenario: CA-FE-02 Hoja inferior en móvil
    Dado una ventana de 390 px
    Cuando toco "+ Tarea"
    Entonces la hoja "Nueva tarea" sube desde abajo con el asa de arrastre

  Escenario: CA-FE-03 Cerrar deslizando
    Dado la hoja abierta sin cambios
    Cuando la arrastro hacia abajo más del 30 % de su alto
    Entonces se cierra y el foco vuelve a "+ Tarea"

  Escenario: CA-FE-04 Confirmar antes de descartar
    Dado que escribí un título en "Nueva tarea"
    Cuando presiono Esc
    Entonces aparece "¿Descartar cambios?" con "Seguir editando" y "Descartar"

  Escenario: CA-FE-05 Confirmación destructiva por texto
    Dado el diálogo "Eliminar Taller de Base de Datos"
    Cuando escribo "Taller de Base de"
    Entonces "Eliminar materia" sigue deshabilitado
    Y cuando completo "Taller de Base de Datos" se habilita

  Escenario: CA-FE-06 Foco atrapado
    Dado un modal abierto
    Cuando presiono Tab repetidamente
    Entonces el foco recorre solo los elementos del modal
```

## 3. Criterios de aceptación no funcionales (CA-NF)
