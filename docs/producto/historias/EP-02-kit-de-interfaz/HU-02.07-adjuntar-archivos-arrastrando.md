# HU-02.07 · Adjuntar archivos arrastrándolos o pegando un enlace o DOI

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **dueño del Olimpo**, quiero **adjuntar mis propias fuentes arrastrando PDF o pegando enlaces y DOI**, para **que el Olimpo use material que ya tengo**. |
| **Contexto** | El panel «Subir fuentes» se usa en el encargo (HU-06.01). Las fuentes van a Supabase Storage. |
| **Reglas de negocio** | RN-1: se aceptan PDF de hasta 25 MB cada uno y hasta 10 archivos por encargo. · RN-2: un DOI se reconoce con el patrón `10.\d{4,9}/…` y se verifica su existencia (en este sprint, con una respuesta simulada). · RN-3: un enlace debe ser `https://`. · RN-4: tres estados visuales: reposo, arrastrando y subiendo con porcentaje. · RN-5: los archivos rechazados muestran el motivo («Solo PDF», «Supera 25 MB»). |
| **Datos** | `{ tipo: 'pdf' \| 'doi' \| 'url', nombre, tamano?, progreso, estado }`. |
| **Supuestos** | La subida real a Storage se conecta en HU-06.01. |
| **Fuera de alcance** | Descargar fuentes desde enlaces (lo hace Atenea en el worker). |

```gherkin
Característica: Adjuntar fuentes

    Cuando suelto <archivo>

    Ejemplos:
      | archivo            | mensaje                         |
      | notas.docx         | Solo se aceptan archivos PDF.   |
      | libro.pdf (40 MB)  | El archivo supera los 25 MB.    |

  Escenario: CA-FE-04 Pegar un DOI
    Cuando pego "10.1000/xyz123"
    Entonces aparece la fila "DOI · 10.1000/xyz123 · verificado ✓"

  Escenario: CA-FE-05 Elegir archivos con el teclado
    Cuando enfoco "Elegir archivos" y presiono Enter
    Entonces se abre el selector de archivos del sistema
```
