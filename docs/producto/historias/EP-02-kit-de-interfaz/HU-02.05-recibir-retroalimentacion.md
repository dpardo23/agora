# HU-02.05 · Recibir retroalimentación con toasts, progreso, esqueletos y estados vacíos

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **estudiante**, quiero **que la plataforma me confirme lo que hice, me muestre lo que está cargando y me oriente cuando no hay datos**, para **no quedarme sin saber qué pasó**. |
| **Contexto** | Estos componentes cubren los estados de carga, vacío y error que exige `docs/design.md` sección 12 en todas las pantallas. |
| **Reglas de negocio** | RN-1: **Toast** abajo a la derecha (en móvil, centrado sobre la barra inferior), 5 s, máximo 3 apilados; con «Deshacer» si la acción es reversible; se pausa al pasar el puntero o al enfocarlo. · RN-2: un toast de error no se cierra solo y ofrece una acción («Ver», «Reintentar»). · RN-3: **Progreso** determinado (con valor) o indeterminado. · RN-4: **Esqueleto** con la forma del contenido final; se muestra solo si la carga supera 300 ms. · RN-5: **Estado vacío** con título, una línea de ayuda y una acción. · RN-6: **Tooltip** tras 400 ms al pasar el puntero o enseguida al enfocar; se cierra con Esc. · RN-7: **Insignias** de contador y de motor (Claude rosa, Gemini cielo, Python neutra). |
| **Datos** | `useToast().mostrar({ tipo, texto, accion?, deshacer? })`. |
| **Supuestos** | |
| **Fuera de alcance** | Notificaciones push (HU-16.03). |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Recibir retroalimentación

  Escenario: CA-FE-01 Toast con Deshacer
    Cuando se encarga un trabajo
    Entonces aparece el toast "Encargo #17 enviado al Control maestro" con "Deshacer"
    Y desaparece a los 5 segundos si no interactúo

  Escenario: CA-FE-02 Deshacer revierte la acción
    Dado el toast con "Deshacer" visible
    Cuando hago clic en "Deshacer"
    Entonces la acción se revierte y el toast se cierra

  Escenario: CA-FE-03 Toast de error persistente
    Cuando falla la compilación del #12
    Entonces aparece "No se pudo compilar el LaTeX del #12" con "Ver"
    Y sigue visible hasta que lo cierro

  Escenario: CA-FE-04 Esqueleto solo en cargas lentas
    Dado una consulta que tarda 800 ms
    Entonces se muestra el esqueleto con la forma de la lista
    Pero si la consulta tarda 100 ms no se muestra ningún esqueleto

  Escenario: CA-FE-05 Estado vacío con acción
    Dado que no hay documentos
    Entonces veo "Sin documentos todavía", "El primer encargo aparece aquí." y el botón "Nuevo encargo"

  Escenario: CA-FE-06 Tooltip accesible
    Cuando enfoco "Pausar agente"
    Entonces aparece "Pausa al agente sin perder la cola" y desaparece con Esc
```

## 3. Criterios de aceptación no funcionales (CA-NF)

|---|---|---|---|---|
