# HU-02.03 · Elegir opciones en select, combobox, multiselección y menú contextual

## 1. Descripción

| Parte | Contenido |
|---|---|
| **Plantilla** | Como **estudiante**, quiero **elegir materias, docentes, prerrequisitos y acciones desde listas que puedo filtrar y recorrer con el teclado**, para **completar formularios y actuar sobre filas rápidamente**. |
| **Contexto** | Se usan en el encargo (materia), Agregar materia (docente, prerrequisitos), Documentos (acciones por fila) y Tareas. |
| **Reglas de negocio** | RN-1: **Select**: lista con la opción elegida marcada con «✓»; las materias llevan un punto con su color. · RN-2: **Combobox**: filtra sin distinguir mayúsculas ni tildes; si no hay coincidencias, muestra «Sin coincidencias» y «+ Crear «texto»». · RN-3: **MultiSelect**: chips con «×»; sugerencias como «+ Nombre»; no admite duplicados. · RN-4: **ContextMenu**: la acción destructiva va al final, separada y en `--warn`. · RN-5: en móvil (< 768 px), las cuatro se abren como **hoja inferior** (HU-02.06), con búsqueda arriba. · RN-6: teclado: ↑ ↓ para moverse, Enter para elegir, Esc para cerrar, y escribir para saltar a la opción. |
| **Datos** | Opciones `{ valor, etiqueta, color?, meta? }`. |
| **Supuestos** | Listas de hasta 200 opciones (no hace falta virtualizar). |
| **Fuera de alcance** | La lógica de crear el elemento nuevo (la define cada pantalla). |

## 2. Criterios de aceptación funcionales (CA-FE)

```gherkin
# language: es
Característica: Elegir opciones en desplegables

  Escenario: CA-FE-01 Elegir una materia en el select
    Dado el select "Materia" con "Estadística II" elegida
    Cuando lo abro y elijo "Base de Datos II"
    Entonces el select muestra "Base de Datos II" con su punto cielo
    Y la opción queda marcada con "✓" la próxima vez que lo abro

  Escenario: CA-FE-02 Filtrar sin tildes en el combobox
    Dado el combobox "Docente" con la opción "Ramírez"
    Cuando escribo "rami"
    Entonces la lista muestra "Ramírez"

  Escenario: CA-FE-03 Crear desde el combobox sin coincidencias
    Cuando escribo "ra" y no hay coincidencias
    Entonces veo "Sin coincidencias" y la opción "+ Crear «ra»"

  Escenario: CA-FE-04 Agregar y quitar prerrequisitos
    Dado la multiselección con "Base de Datos I" y "Matemática Discreta"
    Cuando hago clic en "+ Programación"
    Entonces aparece el chip "Programación"
    Y al hacer clic en la "×" de "Base de Datos I" ese chip desaparece

  Escenario: CA-FE-05 Menú contextual con acción destructiva al final
    Cuando abro el menú "⋯" de un documento
    Entonces veo "Abrir PDF", "Abrir carpeta en Drive ↗", "Regenerar con cambios", "Generar tarjetas de repaso"
    Y al final, separado, "Eliminar documento" en color --warn

  Escenario: CA-FE-06 Operar solo con teclado
    Dado el foco en el select "Materia"
    Cuando presiono Enter, luego ↓ dos veces y Enter
    Entonces queda elegida la tercera opción y el foco vuelve al select

  Escenario: CA-FE-07 Hoja inferior en móvil
    Dado una ventana de 390 px
    Cuando toco el select "Materia"
    Entonces se abre la hoja "Elegir materia" con búsqueda y "+ Agregar materia"
```
